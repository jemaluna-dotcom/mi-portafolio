# Guía del Laboratorio 03

Explicación de cómo trabajar con ramas y colaboradores en Git y GitHub.

## Sobre este proyecto

Este trabajo muestra cómo crear ramas, fusionarlas y resolver conflictos cuando varias personas modifican el mismo archivo.

## Pasos para usar este repositorio

1. Crear un repositorio propio en GitHub
2. Clonarlo a tu computadora con `git clone <dirección>`
3. Crear una rama nueva con `git checkout -b nombre-rama`
4. Realizar cambios y hacer commit
5. Subir la rama y abrir un Pull Request

## Comandos más utilizados

| Comando | Para qué sirve |
|---------|---------------|
| git branch | Ver las ramas existentes |
| git checkout -b | Crear y cambiarse a una rama nueva |
| git merge | Fusionar una rama con la principal |
| git pull | Traer los cambios desde GitHub |
